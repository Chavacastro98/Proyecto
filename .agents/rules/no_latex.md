# Regla: Prohibición de LaTeX en Respuestas y Artefactos

No utilizar sintaxis LaTeX (`$...$`, `$$...$$`, `\text{}`, `\frac{}`, `\Omega`, etc.) porque la interfaz del IDE no dispone de motor KaTeX y muestra el código fuente crudo.

Utilizar exclusivamente:
- Unidades estándar: `1.5 A`, `600 ms`, `100 Hz`.
- Unicode directo: `Ω`, `±`, `≈`, `·`, `°C`, `μ`, `Δ`.
- Ecuaciones en texto plano o bloques de código legibles.
