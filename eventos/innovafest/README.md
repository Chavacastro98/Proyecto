## 📸 3. Galería Fotográfica por Hitos del Proyecto

El material fotográfico se encuentra organizado cronológica y temáticamente en [`galeria/`](galeria/):

```
galeria/
├── 01_montaje_celdas/       <- Construcción de tinas acrílicas, bancada mecánica y soportes de electrodos (Mayo - Junio)

├── 03_prototipo_final/      <- Gabinete de control, instrumentación electrónica integrada y cableado (Finales Julio)
├── 04_sesion_pitch/         <- Sesión de grabación, presentación del equipo y demostraciones en vivo (Agosto)
├── whatsapp/                <- Registro fotográfico de seguimiento técnico continuo
└── archivo_crudo/           <- Ráfagas de fotos secuenciales y respaldos fotográficos
```
