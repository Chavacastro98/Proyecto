## 📂 Estructura Estandarizada por Evento

Cada subdirectorio de evento sigue una jerarquía estricta y limpia:

1. **`documentos_oficiales/`**: Formularios de postulación, cartas de aceptación, fichas de registro, memorias in extenso y dictámenes técnicos.
2. **`pitch_y_presentaciones/`**: Diapositivas ejecutivas, videos demostrativos, guiones de pitch, logotipos institucionales y material para el jurado.
3. **`galeria/` / `cartel_cientifico/`**: Evidencia visual curada por hitos cronológicos, tomas de alta resolución y archivos imprimibles listos para exposición.
